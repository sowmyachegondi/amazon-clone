# Amazon Clone

A simple Amazon homepage clone built using HTML and CSS as a frontend practice project. This project replicates the basic layout and design of the Amazon homepage to improve my frontend development skills.

## Features

- Amazon-style navigation bar
- Search bar
- Hero section
- Product cards
- Footer
- Clean and responsive layout

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Font Awesome (Icons)
- Canva (for editing and preparing images)
- CDNJS (for importing the Font Awesome CSS library)
